## 👨‍💻 Sobre mí

Soy **Romel**, Ingeniero en Tecnologías de la Información y desarrollador de software enfocado en crear aplicaciones web, sistemas empresariales y soluciones tecnológicas.

Me interesa especialmente transformar problemas reales en **sistemas funcionales, escalables y fáciles de mantener**.

```text
💻 Desarrollo de Software
🌐 Aplicaciones Web
🏢 Sistemas Empresariales
🗄️ Diseño y gestión de Bases de Datos
🔐 APIs y autenticación
☁️ Arquitectura y despliegue
🚀 Emprendimiento tecnológico
```

Actualmente combino mi formación en **Ingeniería en Tecnologías de la Información** con el desarrollo de proyectos propios y soluciones para necesidades reales.

No busco únicamente escribir código.

# 💼 Proyectos destacados

## 🐾 GestiónVeterinaria

Sistema de gestión para clínicas veterinarias diseñado para centralizar la información de clientes, mascotas, médicos, citas e historia clínica.

### Características

* 👤 Gestión de clientes
* 🐶 Gestión de mascotas
* 👨‍⚕️ Gestión de médicos
* 📅 Gestión de citas
* 💉 Vacunación
* 📋 Historia clínica
* 📦 Inventario
* 🔐 Autenticación y roles
* 📊 Dashboard administrativo

### Tecnologías

`Vue 3` `TypeScript` `Vite` `Pinia` `Tailwind CSS` `Spring Boot` `PostgreSQL`

## 🏢 Gestora System

Sistema ERP/POS orientado a empresas ecuatorianas, con enfoque en gestión empresarial y facturación electrónica.

El proyecto contempla diferentes módulos para administrar la operación de una empresa desde una plataforma centralizada.

### Áreas principales

* 🏢 Empresas
* 🏪 Establecimientos
* 👥 Clientes
* 👨‍💼 Usuarios
* 🧾 Ventas
* 📦 Inventario
* 🏷️ Productos
* 💰 Formas de pago
* 🔐 Roles y permisos
* 📄 Facturación electrónica
* 🇪🇨 Integración con procesos del SRI
* 🏢 Arquitectura multiempresa

### Tecnologías

`Laravel` `Livewire` `PHP` `MySQL` `JavaScript` `Eloquent`
